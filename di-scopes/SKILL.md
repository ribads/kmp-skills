# core:discopes — DI Scope Annotations

**Module**: `core:discopes` | **Artifact**: `com.ribads.synapse:core-discopes`
**Packages**: `com.ribads.synapse.core.discopes`; see [Imports](#imports)

```kotlin
commonMain.dependencies {
    implementation("com.ribads.synapse:core-discopes:<version>")
}
```

## Setup

`core-discopes` exposes the kotlin-inject runtime (`me.tatarka.inject:kotlin-inject-runtime-kmp:0.9.0`)
as an `api` dependency, so `@Component`, `@Inject`, `@Provides` and `@Scope` resolve without
declaring the runtime yourself. If you declare it anyway, keep it at the same version.

The module ships only the annotation, not generated code. Every module that declares a
`@Component` still applies the KSP plugin (`com.google.devtools.ksp`, 2.3.6) and adds the
kotlin-inject processor (`me.tatarka.inject:kotlin-inject-compiler-ksp`, same version as the
runtime). Processing the common source set generates `KClass<T>.create()` for common code:

```toml
# gradle/libs.versions.toml
[versions]
ksp = "2.3.6"
kotlinInject = "0.9.0"

[libraries]
kotlin-inject-compiler = { module = "me.tatarka.inject:kotlin-inject-compiler-ksp", version.ref = "kotlinInject" }

[plugins]
ksp = { id = "com.google.devtools.ksp", version.ref = "ksp" }
```

```kotlin
// build.gradle.kts of a module that declares a @Component
import org.jetbrains.kotlin.gradle.dsl.KotlinMultiplatformExtension
import org.jetbrains.kotlin.gradle.tasks.KotlinCompilationTask

plugins {
    alias(libs.plugins.kotlinMultiplatform)
    alias(libs.plugins.ksp)
}

kotlin {
    configureCommonMainKsp()
    sourceSets {
        commonMain.dependencies {
            implementation("com.ribads.synapse:core-discopes:<version>")
        }
    }
}

dependencies {
    add("kspCommonMainMetadata", libs.kotlin.inject.compiler)
}

fun KotlinMultiplatformExtension.configureCommonMainKsp() {
    sourceSets.named("commonMain").configure {
        kotlin.srcDir("build/generated/ksp/metadata/commonMain/kotlin")
    }

    project.tasks.withType(KotlinCompilationTask::class.java).configureEach {
        if (name != "kspCommonMainKotlinMetadata") {
            dependsOn("kspCommonMainKotlinMetadata")
        }
    }
}
```

`/init-project` generates this wiring for every module that needs it.

## API

```kotlin
@Scope
@Target(AnnotationTarget.CLASS, AnnotationTarget.FUNCTION, AnnotationTarget.PROPERTY_GETTER)
annotation class SingletonScope
```

That's the entire public API. This module provides a single scope annotation for use with kotlin-inject.

---

## Usage

```kotlin
// Mark a component as singleton-scoped
@SingletonScope
@Component
abstract class AppComponent {
    abstract val repository: MyRepository
}

// Mark a provided binding as singleton
@SingletonScope
@Provides
fun provideHttpClient(): HttpClient = HttpClient { /* config */ }

// Mark a class as singleton
@SingletonScope
@Inject
class MyRepository(private val api: ApiService)

// Create the component from common code (generated by the KSP processor)
val component = AppComponent::class.create()
```

A scoped binding is created once per component instance: keep the `@SingletonScope` component for
the app's lifetime, or every new instance builds its own "singletons".
